# CHILL N’ KNOCK — Baseline v1.0 (ล็อกเลย์เอาต์หลัก)

**นี่คือ Master Baseline ที่จะใช้แก้ทีละจุดต่อไป** ไม่ใช่เวอร์ชัน Feedback001 ที่ถูกออกแบบใหม่จนเกินขอบเขต

## ฐานที่ใช้
เริ่มจาก `CHILL_N_KNOCK_GitHub_Release` (ก่อนเวอร์ชัน Feedback001) ซึ่งต่อยอดจากโค้ดชุดแรก: Hero “MAKE IT A NIGHT.”, การ์ดแนวนอน, Venue Detail, Booking Stepper และ workspace เดิมของ Runner/Venue

## เปลี่ยนเฉพาะสามอย่างใน v1.0
1. **Typography**: Kanit (หัวข้อ), Noto Sans Thai (ข้อความไทย), DM Sans (อังกฤษ/ตัวเลข) โหลดจาก Google Fonts
2. **Mac/Desktop shell**: เอา `TONIGHT IS YOURS.` ที่โผล่ด้านข้างออก เหลือแอปมือถือกว้าง 448px กลางจอและพื้นหลังเรียบ; ไม่มีกรอบโค้งสองชั้น
3. **อ่านง่ายขึ้นเล็กน้อย**: ปรับขนาดหัวข้อที่ใช้ฟอนต์ใหม่ให้ไม่ล้น และขยายตัวอักษร Bottom Navigation เล็กน้อย

**ไม่ได้แก้ flow / จำนวนหน้า / ระบบจอง / สีหลัก / การ์ด / รายชื่อร้านในโค้ดเดิม** ข้อเสนอหรือ Feedback001 ที่ยังไม่ได้แก้ในฐานนี้จะค่อยนำมาใช้ในรอบถัดไปตามคำสั่งเฉพาะจุด

## เปิดใน VS Code
1. แตกไฟล์ ZIP หนึ่งครั้ง แล้วเลือก **File → Open Folder** → `CHILL_N_KNOCK_BASELINE_v1.0`
2. ติดตั้งส่วนขยาย Live Server (ถ้ายังไม่มี)
3. คลิกขวา `index.html` → **Open with Live Server**
4. ทดสอบบน Mac และใช้ Responsive Device Toolbar หรือเปิดบนมือถือ

## อัปขึ้น GitHub Pages
นำ **เนื้อหาภายใน** โฟลเดอร์นี้ไปวางที่ Root ของ Repository เพื่อให้ `index.html` อยู่ที่ Root จากนั้นไปที่ `Settings → Pages → Deploy from a branch → main → /(root)`

## แก้ไขทีละจุดต่อจากนี้
- `styles.css` = CSS ต้นฉบับ (เก็บไว้)
- `polish.css` = ธีมครีมที่เคยอนุมัติ (เก็บไว้)
- **`baseline.css`** = ฟอนต์และหน้าจอ Desktop ที่เปลี่ยนในรอบนี้; ใช้เป็นจุดอ้างอิง
- `app.js` = โครงหลักเวอร์ชันก่อน Feedback001 (เก็บไว้)
- `upgrade.js` = ฟีเจอร์เดิม เช่น การจอง 4 วิธี, บัญชีทดลอง, แปลข้อความไทย, รายชื่อ 18 ร้าน (เก็บไว้)
- `assets/` = ภาพบรรยากาศชั่วคราว
- `docs/` = ข้อมูลประกอบโครงการ/ขอบเขตระบบจริง

**ตั้งหลักการ:** ก่อนเปลี่ยนรอบใหม่ ให้สร้าง Git commit เช่น `baseline: approved v1.0` แล้วแก้เฉพาะหน้าที่ร้องขอเท่านั้น ไม่เขียนไฟล์แอปใหม่ทั้งชุด

## ข้อจำกัด (สำคัญ)
นี่เป็น Interactive Prototype บน Static Hosting ข้อมูลบางส่วนเป็นตัวอย่าง ไม่มี Backend ข้ามอุปกรณ์, ระบบชำระเงิน, ยืนยันตัวตนจริง หรือการจองกับร้านจริง อย่าใช้รหัสผ่านหรือเอกสารส่วนตัวจริงในตัวต้นแบบ

การทดลองสลับบทบาทเพื่อทดสอบ UX สามารถเปิด `?qa=1` แต่ **ไม่ใช่ระบบให้สิทธิ์ Production**

รูปภาพที่นำมาใช้ในโค้ดยังเป็นภาพตกแต่ง ไม่ใช่รูปสถานที่จริง หากต้องใส่รูปที่มีสิทธิ์ใช้ โปรดอ่าน `assets/venues/README.md`
